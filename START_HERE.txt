## 🎨 CUSTOMIZATION

### Change Colors:
1. Open styles.css
2. Find lines 10-25 (CSS Variables)
3. Change hex color codes
4. That's it! Entire site updates

Example:
--primary-color: #6366f1;    (Change to #3b82f6 for blue)
--secondary-color: #8b5cf6;  (Change to #8b5cf6 for purple)

### Change Text/Content:
1. Open index.html
2. Find the section you want to edit
3. Replace the placeholder text
4. Save and refresh browser

### Add More Items:
- Copy-paste section and update content
- Website layout adjusts automatically
- Same styling applied to new items
