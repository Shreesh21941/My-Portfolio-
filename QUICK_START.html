❓Frequently Asked Questions

Can I use my own domain?
Yes! GitHub Pages, Netlify, and Vercel all support custom domains. Check their docs for setup.
How do I change the color scheme?
Edit the CSS variables in styles.css (lines 10-25). No coding knowledge needed - just change the hex colors!
Can I add more projects?
Absolutely! Copy-paste one of the project cards and update the content. It will automatically adjust the layout.
Do I need to know coding?
Not really! For basic customization, you just need to find-replace text. All code is documented and simple to modify.
How do I make the contact form work?
Currently it shows a message. To send real emails, use Formspree.io (free) or EmailJS. See README.md for details.
