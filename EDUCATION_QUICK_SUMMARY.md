## 📝 How to Customize

### **Quick Edit Checklist**

```
[ ] School Name: Replace "Your School Name"
[ ] School Years: Replace "2010 - 2016"
[ ] School Score: Replace "Score: 85%"
[ ] School Stream: Replace "Science (Physics...)"
[ ] School Description: Write your experience

[ ] Diploma Name: Replace "Your Polytechnic College Name"
[ ] Diploma Years: Replace "2016 - 2019"
[ ] Diploma CGPA: Replace "CGPA: 8.2/10"
[ ] Diploma Major: Replace "IT - Web Development..."
[ ] Diploma Description: Write key learning points

[ ] University Name: Replace "Your University Name"
[ ] University Years: Replace "2019 - 2023"
[ ] University CGPA: Replace "CGPA: 8.5/10"
[ ] Major/Minor: Replace "Computer Science | Data Science"
[ ] University Description: Write comprehensive details
```

### **Easy Customization Examples**

**Change School Name:**
```html
<!-- BEFORE -->
<p class="education-institution">Your School Name</p>

<!-- AFTER -->
<p class="education-institution">St. Mary's High School</p>
```

**Update Year Range:**
```html
<!-- BEFORE -->
<span class="education-year-range">
    <i class="fas fa-calendar"></i> 2010 - 2016
</span>

<!-- AFTER -->
<span class="education-year-range">
    <i class="fas fa-calendar"></i> 2015 - 2020
</span>
```

**Update Score:**
```html
<!-- BEFORE -->
<span class="education-score">
    <i class="fas fa-star"></i> Score: 85%
</span>

<!-- AFTER -->
<span class="education-score">
    <i class="fas fa-star"></i> Score: 92%
</span>
```

**Write Description:**
```html
<!-- BEFORE -->
<p>Completed secondary education with strong foundation in core subjects...</p>

<!-- AFTER -->
<p>Completed my high school with distinction. Studied Physics, Chemistry, 
and Mathematics at advanced level. Participated in science olympiads and 
won the state-level programming competition in 2015.</p>
```
